# 연구자 프로필

## 확인된 운영 목표
채용공고와 과제 RFP를 누적해 어떤 연구를 어떻게 할지 정리한다. Claude Code가 이 로컬 저장소를 읽고 갱신한다.

## 확인이 필요한 개인 제약
목표 직무와 연구 성과의 비중: 미확인
현재 보유 역량과 증빙: 미확인 — 미보유로 해석하지 않는다.
지속할 관심 분야와 제외할 분야: 미확인
주당 사용 가능한 시간: 미확인
장비·클라우드 예산·데이터 접근: 미확인
명시적 마감일: 미확인
기밀자료 처리 정책: 미확인

현재 대화나 저장소에 이미 확인된 정보가 있으면 출처·확인일과 함께 갱신한다. 개인 제약이 비어 있어도 분석을 중단하지 말고 조건부 실험을 제안한다. 사용자 동의 없이 예산·시간·성과 목표를 확정하지 않는다.
